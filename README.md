# ERP Nova

ERP Nova is a Full Stack Enterprise Resource Planning (ERP) application developed as part of a guided Full Stack Bootcamp. The project aims to simulate the development of a real-world enterprise application while applying modern software engineering principles, clean architecture, and industry-standard development practices.

---

## Project Goals

- Learn Full Stack Development from the ground up.
- Build a complete enterprise-grade application.
- Apply software engineering best practices.
- Maintain a clean and well-documented Git history.
- Learn technologies commonly used in the software industry.
- Deploy the application using modern DevOps practices.
