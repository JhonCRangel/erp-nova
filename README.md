# ERP Nova

ERP Nova es un proyecto Full Stack desarrollado como parte de un bootcamp práctico, con el objetivo de aprender desarrollo de software utilizando herramientas y prácticas profesionales.

## Objetivos

- Aprender Git y GitHub.
- Desarrollar un frontend moderno.
- Construir una API REST.
- Trabajar con PostgreSQL.
- Utilizar Docker para contenerización.
- Desplegar la aplicación en la nube.

## Tecnologías (en construcción)

- Git
- GitHub
